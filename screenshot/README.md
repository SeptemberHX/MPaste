# screenshot

> 一旦我所属的文件夹有所变化，请更新我。
- 定位：screenshot 目录承载产品界面截图。
- 依赖：文档、发行说明与展示场景。
- 输出：用于说明产品效果的截图资源。

## Files
- `panel-still-dark.png` / `panel-still-light.png` / `panel-aurora-dark.png`: 地位=位图资源；功能=底部面板（静物深色、静物浅色、流光深色），含新样式的链接卡片。
- `preview.png`: 地位=位图资源；功能=空格预览一张长图，叠在面板上方。
- `details.png`: 地位=位图资源；功能=详情窗口（图片条目：预览、信息、格式）。
- `onboarding.png`: 地位=位图资源；功能=首次启动引导的快捷键一步。
- `quick-paste-stack.png`: 地位=位图资源；功能=光标旁的快速粘贴堆栈（0.8.0 时拍摄，界面未变）。
- `settings.png`: 地位=位图资源；功能=设置窗口的文字识别页。
- 除堆栈外均由 `tools/screenshots/take.py` 在隔离的 GNOME 51 会话中拍摄（2880 × 1800，2 倍缩放，存为 1×），英文界面；内容由借用系统应用身份的示例程序复制的虚构数据，不含真实剪贴板历史。界面改动后重新运行该脚本即可更新。
- `README.md`: 地位=目录说明；功能=总结本目录职责、约束与文件清单。
